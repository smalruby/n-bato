# 公開するリポジトリと、手元だけに置く情報

## 状況と問題

n-bato は公開リポジトリにする。利用団体の会員・役員の情報や金額、内部の情報が入ってはいけない。

## 判断の基準

* 個人情報と団体の内部の情報が、ファイルにも履歴にも入らないこと
* 安全側に倒した、広い検査

## 検討した選択肢

* 人の注意だけで守る
* 手元だけの置き場所を決め、コミットの前と CI で自動的に調べる

## 決定

採用:「手元だけの置き場所と、自動の検査」。

* 手元だけ: 会員・役員・関係者の氏名・連絡先、金額、内部の情報(決めたこと・作業記録)、非公開のリンク、鍵。置き場所は CLAUDE.local.md・notes/・data/・storage/・.env・config/master.key。
* bin/check-private が、鍵の形と、個人情報らしい形(電話・郵便番号・メール・都道府県名・住所・全角スペースの氏名)を広く調べる。許すのは config/check_private_allow.yml に理由と出どころを書いた、架空の例と公的機関の公開情報だけ。
* 手元では .private-patterns(手元だけ)の語も調べる。pre-commit フックと CI(ファイルと履歴のすべてのコミット)で動く。
* 公開の前に、履歴を 1 から作り直した。

### 確かめ方

CI の scan_private。CLAUDE.md「公開リポジトリとしての注意」。
