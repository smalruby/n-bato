# Slack との連携 — 見直し票 第10回・第11回

## 状況と問題

期限のリマインドや記録の知らせを、法人の Slack に流したい。Slack から依頼を作れるとよい。

## 検討した選択肢

* Slack にいる人: 役員だけ / 役員と正会員 / 保護者・子ども・外の人もいる
* 知らせるもの: 期限のリマインド・締めた年度の変更・監査や締めや提出の記録・フォームの回答の到着
* Slack からやることを作る: メッセージのメニューから依頼の対話に下書きを送る / 作らない
* 動かす場所: まず手元で(Socket Mode) / 本番に出してから

## 決定

* ワークスペースには外の人もいるので、限られた人だけのチャンネルに流し、個人情報は流さない
* 期限のリマインド(週 1 回のまとめと 3 日前・当日)、締めた年度の変更、監査・締め・提出の記録を知らせる
* メッセージのメニュー「Nばとのやることにする」で、依頼の対話に下書きを送る。決めるのは n-bato で人
* まず手元で、Socket Mode(外から入る口を開けない)で始める
* 外の仕組みとつなぐときは、組み込む前に人と一緒に実際に動くかを確かめる

### 理由

* 推測: 外の人もいる場所なので、知らせの中身を最小限にした
* 推測: 記録の正はシステムに置き、Slack は人に知らせる窓口にとどめた
