# 入会申込の受け箱 — 見直し票 第11回

## 状況と問題

入会の申込がフォームで届いても、システムの中で受けて「入会を認める」までの流れがなかった。あわせて、AI の推奨で決めたこと(伏せ方・自動で済みにする決まり)を確かめた。

## 検討した選択肢

* 入会申込: 受け箱と「入会を認める」を作る / 申込が来たら会話で進める
* 伏せ方: 住所・電話・メール・郵便番号と登録されている人の連絡先を伏せ、添付は送るかを人が選ぶ
* 自動で済みにするもの: 提出の記録・年度を締めた記録だけ

## 決定

* 受け箱を作り、状態は 届いた・認めた・認めない。届いたものは「やること」にも出す
* 伏せ方と自動で済みにする決まりは、推奨どおり

### 理由

* 推測: 定款の「入会は理事長が認める」の流れを、記録に残る形で回すため

## 補足

入会はイミュータブルデータモデルでは長いイベント(申込・認める・認めない)。会員の業務を移すときに作り直す(ADR-0002)。
