# やることと依頼 — 見直し票 第9回

## 状況と問題

所轄庁などからの依頼と、定款・法律の義務の期限、年に一度の手続きの次の手順が、ばらばらに管理されていた。

## 検討した選択肢

* 置き場所: 左のメニューに「やること」を作って 1 つの一覧に / ホームに足すだけ
* 年度: 年度をまたいで 1 つの一覧(1 件の対象は 1 つの年度か年度なし) / 年度ごとに入れる
* AI との対話: 依頼ごとの対話 / 右ペインの「AI に聞く」だけ
* 依頼の文を外部の API に送るとき: 住所・電話・メールを伏せて人が確かめてから送る / そのまま送る / AI に送らない
* 済みの決め方: 4 つの状態と、記録で確かめられるものは自動で済み / 未・済みの 2 つで人が押す
* システムの外でやること: 種類(画面・書類・人に聞く・電話や窓口)を持たせる / 画面で解決できるものだけ
* 依頼が全部済んだら: AI が送付状か返信の下書きを作る / 解決にするだけ

## 決定

* 左のメニューに「やること」を作り、依頼・義務・手続きを 1 つの一覧にする。ホームには期限の近いものだけ
* やることは年度のデータの束の外に置き、年度をまたぐ一覧にする
* 依頼ごとに AI との対話を持つ。送る前に住所などを伏せ、人が確かめてから送る
* 状態は 未着手・作業中・待ち・済み。記録で確かめられるものは自動で済み
* やることに種類を持たせ、システムの外の作業も扱う
* 依頼が全部済んだら、AI が送付状か返信の下書きを作る(送るのは人)

### 理由

* 推測: 人がやるべきことを 1 か所で見て、取りこぼしを無くすことを優先した
* 推測: 外部の API への送信は、伏せてから人が確かめることで、個人情報の決まりと便利さを両立させた
