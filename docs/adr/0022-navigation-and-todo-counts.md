# 左のメニューと、やることの件数 — 見直し票 第12回

## 状況と問題

左のメニューで、区切りの見出しとページの見分けがつかなかった。やることがあることに気付きにくかった。

## 検討した選択肢

* 見出し: 小さい灰色の見出しと区切り線 / 線だけ / 押すと畳める
* ページのアイコン: 付ける / 文字だけ
* 件数のまとめ: 期限と担当ごとの札(押すと絞る) / 1 行の文 / 出さない
* メニューの件数: 期限を過ぎた数(なければ 7 日以内) / 済んでいないすべての数 / 両方

## 決定

* 見出しは押せない小さい灰色の文字と区切り線。ページにはアイコンを付ける
* やることの画面とホームに、期限・担当ごとの札を置き、押すと絞る
* メニューの「やること」には、期限を過ぎた数(赤)。なければ 7 日以内(黄)。どちらも 0 なら出さない

### 理由

* 多いままの数は見慣れて見落とすので、急ぐものがあるときだけ目立たせた
* 推測: 「いつ使うページか」の手がかり(ふだん・年に一度)は残した
