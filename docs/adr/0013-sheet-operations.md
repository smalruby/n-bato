# 表(シート)の操作 — 見直し票 第1回

## 状況と問題

仕訳の表で、保存されたか・何が元に戻ったか・どこに入力するかが分かりにくかった。Excel に慣れた事務の人が毎日使う画面として、操作を決める。

## 検討した選択肢

* 年度の切り替え: 上の選択欄と下のタブの両方を残す / 下のタブを消して上だけにする
* 開いたときの年度: 前に見ていた年度 / いつも今年度 / 締めていない最も古い年度
* 日付を直して年度の外に出たとき: 保存して知らせる / 保存前に確かめる / 年度の外の日付は入れられないようにする
* 日付を直した行: 開き直すまでその場所 / すぐ正しい位置へ移して色で見せる
* 保存の知らせ: 直したセルを光らせる / 右上だけ。Esc の取り消し: セルの下に出す / 説明欄だけ
* 元に戻す: 戻した行へ移って光らせる / 移らず文で出す。ボタンに戻る項目を出す / 回数だけ
* 科目の選び方: 打って絞り込む欄 / ドロップダウン。新しい仕訳: 表の最後の空の行 / 別の画面
* 表の下: 件数と選んだ行の合計 / 件数だけ。絞り込み: 表の上の欄 / 見出しから / なし

## 決定

* 下のタブを消し、年度は上部バーで扱う。開いたときは「作業する年度」を出す(ADR-0014)
* 年度の外の日付は入れず、その年度に切り替えるかを聞いてから移る
* 直した行はすぐ正しい位置へ移し、色で見せる。行番号は消して伝票番号だけ
* 保存はセルを光らせて知らせる。Esc の取り消しはセルの下に出す
* 元に戻すは、戻したところへ移って光らせ、ボタンに戻る項目を出す
* 科目・部門は打って絞り込む欄(Picker)。新しい仕訳は表の最後の空の行に書く
* 会計ソフトから取り込んだ行を押したら、直せない理由を出す
* 表の下は Excel のように件数と選んだ行の合計。ほかの集計も選べるようにする(ADR-0014)。絞り込みは表の上の欄

### 理由

* Excel と同じ感覚で、1 画面で速く入力できることを優先した(答えのひとこと)
* ふだんは今年度しか操作しないので、過去の年度を誤って操作しないことを重く見た(答えのひとこと)
* 決めた操作はデザインシステムにも書いて、画面ごとにばらばらにしない(答えのひとこと)
