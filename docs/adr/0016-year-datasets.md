# 年度のデータの束(データセット)と、締めた時点の正 — 見直し票 第5回

## 状況と問題

会計以外の情報(会員・役員・法人情報)も年度ごとに持つか、締めた時点の値をどう決めるか、まだ締めていない年度の入力をどう扱うかを決める。

## 検討した選択肢

* 考え方: 会計以外は最新を正とし履歴を持つ / 会計と同じく、締めた時点のデータがその年度の正
* 写しを作る時: 年度末の翌日に自動で作る / 締めるときに作り、日付のある項目は年度末で判定 / 締めたときの状態をそのまま
* 写す項目: 所轄庁の様式に載る項目だけ / 全部
* いまの情報を直したとき、締めた年度の同じ値: 聞いて直す / 聞かない
* いつ締めるか: 提出を記録したときに聞く / 決算のとき / 人が押したとき
* 締めた年度を直したら: 再提出の手順を足してホームに出す / 知らせるだけ
* 次の年度の仮の仕訳: ふつうに入れて「仮」と出す / 下書きとして持つ
* 過去の年度のデータの作り方: 最終版の名簿から作る / いまの情報を写す / 古い年度もすべて作り直す

## 決定

* 会計以外も会計と同じく、締める操作をした時点のデータがその年度の正。過去の年度の値を直すにも理由が要る
* 4 月以降に入った人や選ばれた役員は、次の年度のデータとして入れる(「いま」ではなく年度のデータの束を変える)
* 年度ごとにデータの束を持つ(様式の項目だけに絞らない)
* いまの値を直したとき、締めた年度に同じ値があれば、直すかを聞く(理由を書く)
* 締めは、提出を記録したときに「この年度を締めますか」と聞き、2 回押しで締める
* 締めた年度を直したら、その年度の提出の手続きに再提出の手順を足す
* 仮の年度の仕訳はふつうに入れて「仮」と出し、前の年度を締めると仮が外れる
* 科目を足す・名前を変えると、その年度に効く。締めていないほかの年度にも効かせるかを聞く
* 過去の年度のデータは、所轄庁に出した最終版の名簿から作る。古い年度は提出した PDF を付けておく

### 理由

* 人の考えの整理(答えのひとこと): 一時は「会計以外は最新が正」と思ったが、会計と同じだった
* 推測: 所轄庁に出したものと、システムの年度のデータが一致することを重く見た

## 補足

年度ごとに写すと困るもの(個人を特定する ID など)は、ID を共通にし、属性だけを年度ごとの別のテーブルに持つ(第7回の答え。ADR-0018)。
