# アイコン — 見直し票 第6回

## 状況と問題

元に戻す・やり直すなどが文字の記号で、部品ごとに形がばらばらになるおそれがあった。

## 検討した選択肢

* セット: Lucide / Tabler Icons / Heroicons / Material Symbols
* 元に戻すの形: 曲がった矢印 / U ターンの矢印 / 回る矢印
* アイコンと文字: 必ず文字を添える / よく使うボタンはアイコンだけ
* 大きさ: 16px・線 1.75(表の中は 14px) / 16px・線 2 / 20px・線 2

## 決定

* Lucide だけを使う。使うものは表に載せ、その SVG だけをアプリに置く
* 元に戻す・やり直すは曲がった矢印(表計算ソフトと同じ形)
* アイコンには必ず文字を添える。アイコンだけのボタンは作らない
* 16px・線 1.75(表の中は 14px)

### 理由

* 推測: 線の細い表の画面になじみ、会計・事務に要る形がそろうこと
* 推測: 年に数回しか使わない画面もあるので、覚えなくても分かることを優先した
