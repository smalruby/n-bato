# 年度の色、年度更新と締め、変更の記録 — 見直し票 第3回

## 状況と問題

年度を画面全体の色で見分けること、次の年度を始める操作、締めた年度の仕訳を直すときの扱いを決める。

## 検討した選択肢

* 年度の色を付ける場所: 地と枠だけ(意味の色は変えない) / ボタンなども年度の色
* 年度更新で写すもの: 科目と部門・期首の残高・会員と役員・法人情報・手続きのメモ
* 締めるとき: 手続きの「決算を締める」を済みにしたとき / 提出を記録したとき / 総会で承認したとき
* 締めた年度の仕訳を直すとき: 理由を書かないと直せない / もう一度押すだけ
* 変更の記録の画面: 作る(年度ごと・締めたあとの変更で絞る・PDF) / 操作履歴で足りる

## 決定

* 年度の色は 5 色(地と枠だけ)。ボタン・保存・エラーなど意味のある色は変えない
* 年度更新で、科目と部門・期首の残高・会員と役員・法人情報・手続きのメモをすべて写す
* 締めは、人が「次の年度を始める」操作をしたときに考える(決算との連動は不要。答えのひとこと)。締める時期の細部は第5回で決めた(ADR-0016)
* 締めた年度の仕訳は、理由を書かないと直せない。理由は変更の記録に残す
* 「変更の記録」の画面を作る(監事に渡す PDF も出せる)

### 理由

* 会計ソフトの「データ次年度更新」と同じ流れにした(答えのひとこと)
* 3 月のうちに次の年度のことを書き始めることがあるので、決算と締めを結びつけない(答えのひとこと)
* 推測: 監事の監査に耐える記録を、仕組みの側で残すため

## 補足

予算の機能は、人もまだ形を決めていないので、2027 年 2〜3 月に AI と一緒に作業しながら作る(答えのひとこと)。
