# 定款と事業のページ — 見直し票 第13回

## 状況と問題

仕訳の部門(事業の区分)が何の事業か、システムからは分からなかった。定款もシステムの中で読めなかった。

## 検討した選択肢

* 置き場所: 左のメニューの上の段に「定款と事業」 / 名前を「法人のこと」 / 設定の中
* 要約のタブの名前: 「ひと目で」 / 「要約」
* 事業ごとの主な活動: 作って部門選びと AI の指示文にも出す / ページだけ / 作らない
* 定款の版: 版ごとに全文と変更の記録 / 現行だけと変更の表
* 条文の参照: その年度の時点の版を右ペインに出す / いつも現行 / 作らない

## 決定

* 左のメニューの上の段に「定款と事業」を置く。タブは 要約・定款の全文・変更の記録
* 事業ごとの主な活動を書き、部門選びと AI の仕訳の指示文にも出す
* 定款は版ごとに全文で残し、前の版との違いを出す。年度には依存しない
* 「定款第○条」を押すと、その年度の時点の版の条文を右ペインに出す

### 理由

* 主な活動を元に事業報告書を書き、年度ごとに活動の実態と一致するように見直していく(答えのひとこと)
* 推測: 設定ではなく、いつでも読む「法人のきまり」として置いた
