# Ruby 4.0 を使う

## 状況と問題

公開前の点検で、Ruby 3.4.1 に重大な脆弱性があると Brakeman が知らせた。

## 検討した選択肢

* Ruby 3.4 の新しいパッチ版(3.4.13)
* Ruby 4.0 の最新(4.0.10)

## 決定

採用:「Ruby 4.0 の最新」(理事長の判断)。テスト・Brakeman・RuboCop が通り、本番(Lightsail、amd64)のイメージも作れることを確かめた。.ruby-version はリポジトリに入れる(CI が読む)。

### 確かめ方

CI(setup-ruby が .ruby-version を読む)と、Brakeman の Ruby の版の検査。
