# 作業する年度と、過去の年度の扱い — 見直し票 第2回

## 状況と問題

4〜6 月は前の年度と今年度を同時に扱う。いまどの年度を操作しているかが分からないと、間違った年度を直してしまう。

## 検討した選択肢

* 作業する年度の決め方: 法人情報の設定で決め、4 月に聞く / 暦で自動に切り替える / 上部バーでいつでも切り替える
* 上部バーの年度: 札(作業する年度)と「他の年度に切り替える」 / 選択欄のまま
* 過去の年度の見た目: 斜線の帯 / 上部バー(画面全体)の色 / 透かし
* 過去の年度を直せるか: 2 回押しで直せるようにする / いっさい直せない / 直せる(注意は最低限)
* 年度の外の日付: 打った内容を持って移る / 移るだけ
* 年度で分ける範囲: 会計と報告だけ / 決議や会員・役員も含めてほぼすべて
* 表の下の集計: 件数・合計・残高・平均など、選べるようにする

## 決定

* 作業する年度は設定で決め、自動では変えない。4 月になったら「次の年度を作業する年度にしますか」と聞く
* 上部バーは作業する年度の札と「他の年度に切り替える」。いつでも切り替えられる
* 年度ごとに色を変え、画面全体で一目で分かるようにする(5 色を巡回。ADR-0015)
* 過去の年度も直せる。注意は最低限。ただし締めた年度の仕訳は毎回警告し、変更をすべて記録する
* 年度の外の日付は、内容を持って移る。元の年度の行も変える。提出済みなら再提出が要ることを示して確かめる
* ほぼすべてのデータを年度ごとに持つ(次の年度に移るときに写す)

### 理由

* 会計ソフトと同じく、年度は明示的に切り替えるものとした(答えのひとこと)
* 電子帳簿の考え方に合わせ、締めた年度の仕訳の変更は、誰がいつ何を変えたかを追えるようにする(不正を見つけられるように。答えのひとこと)
* 「いま」を持つのではなく、「年度」というデータの束を変える考え方(答えのひとこと)
